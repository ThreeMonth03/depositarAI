# 網站互動設計

本頁說明網站的呈現及互動規則。品牌素材見
[品牌說明](SEARCH_WEBSITE_BRANDING.md)，實際 HTTP 契約見[網站設定](SEARCH_WEBSITE.md)。

## 現行介面

- 網站標題、品牌、對話標示統一為 **depositar AI**；內部 Compose service 名稱不改。
- 首頁聚焦自然語言輸入，提供三組探索主題；淺色、綠色系、桌面／手機排版。
- 首頁聚焦找資料；登入及存取範圍由入口設定決定。
- 結果以標題、原始描述、提供單位、格式、資料集連結為主。
  長描述可展開，較早輪次結果可收合，完整資料仍在本次頁面記憶體。
- 未知條件保留輕量的「部分條件待確認」標示。
  篩選範圍、metadata-only、未解析 PDF／CSV、模型／快照版本等資訊
  放入「搜尋詳情」；30 分鐘／20 輪等限制放入「使用說明」。不是刪掉限制或擴大能力宣稱。
- 等待畫面顯示真實經過秒數與 loading placeholder。
  不用假進度百分比，不用計時器假稱解析／檢索／排序已完成。
- 搜尋完成的短句由卡片數目套用固定模板，卡片預覽取原始描述；兩者都不是 LLM 摘要。

目前使用一次 JSON 回應，不提供 SSE／token streaming 或 LLM 摘要。
