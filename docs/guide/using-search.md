# 搜尋資料

從你想研究的事情開始，不必先猜關鍵字。首頁的「河川與水質」、「氣候與變遷」與「土地與生活」也可以作為起點。

## 提出第一個問題

輸入主題後，按「開始探索」。例如：

> 找河川水質觀測資料

你也可以一次說明主題、涵蓋時間與格式：

> 找 2020 到 2025 年的氣候資料

「結果數」可選擇 5、10 或 20 筆。搜尋進行中會顯示處理提示，完成後會列出本次條件與資料集卡片。

每次輸入以 512 個字為限。問題太長時，先提出主要主題，再逐次補充條件。

## 用追問調整條件

接著在同一個輸入框追問，按「繼續搜尋」。每次送出後，先看結果上方的條件標籤，確認系統採用了你的意思。

| 想調整什麼 | 可以這樣說 |
| --- | --- |
| 限定格式 | 「只要 CSV」 |
| 更換涵蓋時間 | 「改成 2024 年」 |
| 移除時間限制 | 「取消時間限制」 |
| 改找另一個主題 | 「改找土地利用資料」 |

若要清楚地從頭開始，選右上方的「＋ 新搜尋」。先前各次搜尋的結果可展開查看，卡片上的條件對應當次搜尋。

## 格式條件表示什麼

「只要 CSV」表示資料集**至少列有 CSV 資源**，不是只允許 CSV 檔案。格式取自資源 metadata，與檔案是否已解析無關。

| 條件 | 意義 |
| --- | --- |
| 至少提供 CSV | 同時列有 CSV 與 PDF 的資料集也符合。 |
| CSV 或 PDF | 格式清單採 OR，列有其中任一格式即可。 |
| 同時提供 CSV 和 PDF | 目前不支援格式 AND，不能當成已套用。 |
| 不要 CSV | 目前不支援排除格式，不能當成已套用。 |

後兩種需求需先釐清或改寫；若是必要條件，請到原始資料集頁面逐項確認。

## 把時間說清楚

時間條件指的是**資料涵蓋的期間**，不是建立、上架或最後更新日期。

- 可使用西元年份，例如「西元 2022 年」，或明確的民國年份，例如「民國 111 年」。
- 只說「最近」時，系統可能會請你補充範圍；可改說「最近一年」或直接給起訖年份。
- 「去年」等相對時間會依本次參考日與時區處理，可在頁面底部的「使用說明」查看。
- 農曆日期會保留為文字搜尋，不換算國曆，也不套用日期篩選。需要精確範圍時，請提供國曆日期。

只指定單一年份時，條件會顯示為「2024 年」；真正的日期區間則保留起訖時間。條件標籤描述本次設定。

未來年份也可作為涵蓋條件，例如「找涵蓋 2035 年的都市規劃資料」；規劃資料可能涵蓋未來，不能只因年份尚未到來就判定沒有資料。

## 閱讀資料集卡片

卡片會列出標題、組織、描述片段，以及資料涵蓋期間與資源格式標籤。描述較長時，可選「展開描述」；找到合適的項目後，選「查看資料集」前往原始頁面。

「資料涵蓋」顯示資料集原本提供的日期，不是本次搜尋年份或上架／更新日期。
例如查詢 2024 年時，涵蓋 2020～2025 年的資料仍可能符合時間重疊條件。
未提供日期、缺少單側日期或日期無法判讀時，標籤會照實註明；缺少結束日期不表示資料持續更新至今。

若出現「部分條件待確認」，代表資料的時間或格式資訊不完整（unknown），仍需到原始頁面確認。搜尋會排除可確定不符合的項目，保留無法判定的項目；例如查詢 2035 年時，日期未知的卡片並不表示已證明涵蓋 2035 年。

展開「搜尋詳情」可以了解本次搜尋範圍。時間與格式在索引召回時套用，再對候選複核；每路檢索與合併候選都有數量上限，顯示筆數不代表整個資料庫的符合筆數。

地名可以作為主題文字的一部分；目前沒有附近、半徑或距離篩選。PDF、CSV 等格式標籤表示資料集列有這類資源，不代表所有檔案都已解析。

目前啟用 catalog 中已索引的資源摘要會在卡片顯示來源連結，以及「CSV 欄位（節錄）」或「檔案摘錄」。欄名以明確選定的第一列政策抽取，CSV 資料列值不進入搜尋；PDF 摘錄是原始文字的有界節錄。這些內容用來找資料集，不提供檔案內文問答或計算。時間標籤仍來自資料集 metadata，不從欄名或摘錄中的年份猜測。

## 下載本次結果清單

最新結果區的「下載清單 CSV」與「下載清單 JSON」可保存已顯示的資料集 ID、順序、標題、組織、連結、格式與涵蓋狀態，以及當次條件、版本與時間。下載只使用這次已送達的清單，不重新搜尋、不下載原始檔案，也不代表全部符合結果。

JSON 包含 `metadata` 與 `items`。CSV 使用 UTF-8；`record_type=metadata` 的一列保存條件與版本等資料，`dataset` 列才是資料集清單。即使零結果，兩種格式仍保留 metadata。CSV 對可能被試算表當成公式的文字加上文字前綴；JSON 保留原值。

清單保存原 catalog 快照身分，不保證來源在下載時仍公開。查詢參考時間與瀏覽器的接收／匯出時間分開標示；來源觀測時間未提供時保留未知，不以其他日期代填。API／BFF 版本保留服務回報的標籤，未宣稱另行驗證該標籤。

一次最多下載 20 筆已顯示結果，檔案上限 1 MiB。若此輪資料不足以確認清單，下載會暫停，搜尋結果仍可閱讀。新搜尋、到期或身分變更會清除頁面中的清單；已下載到個人電腦的檔案須自行保管與刪除。

## 沒有結果或需要補充時

沒有找到結果時，試著放寬年份、移除格式限制，或換成較一般的主題。系統要求補充日期或主題時，直接在同一個搜尋中回答即可。

若提示問題超出資料集搜尋範圍，請改成描述你要找的資料，例如「找河川水質觀測資料」。

澄清（clarify）表示需要補充或調整條件；拒絕（reject）表示請求不屬於可執行的資料集搜尋。這兩種狀態不執行新搜尋，也不替換已套用條件。

| 輸入例子 | 處理原則 |
| --- | --- |
| 「找最近的水質資料」 | 澄清時間，可改說「涵蓋最近一年的水質資料」。 |
| 「找 2024 年最後更新的水質資料」 | 澄清未支援條件；更新日期不能改當資料涵蓋時間。 |
| 「比較第二筆 CSV 裡各站的平均值」 | 澄清未支援條件；需另行取得檔案並分析。 |
| 「幫我寫一支爬蟲程式」 | 拒絕一般程式任務；可搜尋「爬蟲研究資料集」。 |

| 畫面提示 | 下一步 |
| --- | --- |
| 服務忙碌、連線已滿或送出頻率較高 | 稍候，再手動送出一次。 |
| AI 搜尋額度已用完 | 稍後再試；仍可到 [depositar 公開資料站](https://data.depositar.io) 瀏覽。 |
| 要求登入 | 選擇「免費登入」，完成後再開始搜尋。 |
| 搜尋到期、狀態不同步或連線中斷 | 選擇「＋ 新搜尋」，重新提出條件。 |

一次搜尋的條件暫存 30 分鐘，最多 20 輪。重新整理頁面也會重新開始；若要保留找到的資料，可下載本次清單或另存原始資料集網址。
