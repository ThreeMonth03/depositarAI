# depositar AI 使用指南

depositar AI 幫助你用自然語言尋找 depositar 的公開資料集。從研究主題出發，再透過追問調整資料涵蓋時間與格式，逐步找到值得進一步查看的資料。

## 開始探索

1. 開啟網站，輸入想了解的主題，例如「找河川水質觀測資料」。若網站要求登入，先選擇「免費登入」。
2. 查看搜尋條件與資料集卡片，再試著追問「只要 CSV」或「改成 2024 年」。
3. 選擇「查看資料集」，到原始頁面閱讀說明、確認授權及取得資料。

[閱讀完整搜尋說明](using-search.md)

## 搜尋的是什麼

搜尋內容以資料集的標題、描述、組織與資源格式等中繼資料為主。維護者也可選取 CSV 欄位與 PDF 文字節錄加入索引；有這些內容時，卡片會顯示檔案來源及節錄。沒有顯示節錄不代表原檔沒有相關內容。網站不提供檔案內文問答。

同一次搜尋可延續條件，方便反覆調整。這些條件是暫存狀態；開始「新搜尋」或重新整理頁面後，會從頭開始，不建立永久對話記憶。
